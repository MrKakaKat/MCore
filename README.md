# MCore

MCore is an animation editor for Android phones: shapes, text, pictures,
video and sound on a timeline, exported as video, GIF, images or SVG.

**Version 0.1** — an early release. Expect rough edges; projects made with
it may need care when moving to later versions.

## Get it

Download the APK from [Releases](../../releases) and install it on an
Android phone (Android 7.0 or newer, 64-bit). Updates install over the
previous version and keep your projects.

## Build it yourself

With [Flutter](https://flutter.dev) (stable) and the Android SDK:

```sh
flutter pub get
flutter build apk --release
```

How the code is laid out, how to run the checks and how releases are
signed: see [DEVELOPERS.md](DEVELOPERS.md).
